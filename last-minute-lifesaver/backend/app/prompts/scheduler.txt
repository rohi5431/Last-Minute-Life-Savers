- Task durations (fit into available time)

  "schedule_plan": [
    {
      "task_id": 1,
      "scheduled_for": "2026-06-23T14:00:00Z",
      "reason": "Best available slot before deadline"
    }
  ]
}

Only output the JSON, no additional text.
